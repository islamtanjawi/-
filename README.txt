1) Google Apps Script: الصقي محتوى Code.gs مكان الكود القديم، ثم Deploy > Manage deployments > Edit > Version: New version > Deploy (Who has access: Anyone). الرابط /exec يبقى نفسه.
2) GitHub: ارفعي index.html ومجلد images معاً (فك الضغط أولاً)، ثم Settings > Pages > Branch main / root.
3) لا تفتحي index.html من داخل ملف zip مضغوط، فك الضغط أولاً حتى تظهر الصور.
